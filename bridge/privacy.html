Privacy Policy

This policy explains how the personal Obsidian Google Sync OAuth integration and its associated open-source Obsidian plugin handle Google user data.

1. Data accessed

After Google authorization, the plugin can access Google Calendar event information (such as titles, dates, times, descriptions, locations and calendar identifiers) and Google Tasks information (such as titles, due dates, notes and completion status), as permitted by the requested Google API scopes. It also reads and edits notes in the Obsidian folders configured for synchronization.

2. Purpose and use

Google data is used only to import calendar events and tasks into the Obsidian vault, compare them with linked local notes, and apply authorized changes to existing Google items. The plugin does not create or delete Google Calendar events or Tasks. It does not use Google user data for advertising, profiling, sale of data, or training AI models.

3. Storage and retention

Imported event and task information is stored as local Markdown notes in the user's Obsidian vault. Plugin settings and Google OAuth tokens are stored locally in .obsidian/plugins/google-sync/data.json. Data remains there until the user changes or deletes it, including any copies held by the user's own vault backup or synchronization service. This personal integration does not operate a server database storing Google Calendar or Tasks content.

4. Data sharing and transmission

The Obsidian plugin communicates directly with Google APIs to synchronize permitted data. It does not intentionally transfer calendar or task contents, or stored OAuth tokens, to the GitHub Pages website or to an application developer's hosted sync server. No analytics or advertising scripts are included on these informational pages. GitHub, as the website host, may process ordinary website request information under its own privacy terms.

5. OAuth callback

The GitHub Pages callback at https://destbest.github.io/obsidian-google-sync/ receives Google's temporary OAuth response through the browser and forwards the authorization code and state to Obsidian via an obsidian:// link. It does not intentionally save the code on the webpage or exchange it for access tokens. As with other web redirects, URL details may appear temporarily in browser history or hosting-related request logs. Keep your vault and browser secure.

6. User choices and deletion

  • Choose the calendars, task lists, folders, and synchronization options inside the plugin.
  • Disconnect the Google account from the Obsidian plugin.
  • Revoke the app's Google permissions at Google Account connections.
  • Delete imported notes and local plugin data if no longer needed; review separately configured backups and cloud vault synchronization.

7. Security

Google credentials and local notes are sensitive. Protect device access and vault backups; do not publish your Obsidian plugin data file or OAuth tokens. No method of local storage or internet transmission can guarantee absolute security.

8. Changes and contact

This policy may be updated if the integration's functionality or data handling changes. The latest version will be available on this page. For questions, contact the maintainer of this personal configuration via the associated GitHub repository.
