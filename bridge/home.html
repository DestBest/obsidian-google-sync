Personal integration · Google OAuth

Connect Google Calendar and Tasks to Obsidian

Obsidian Google Sync is a personal Google OAuth configuration for the open-source Google Calendar and Tasks Sync plugin. It helps its user keep Google Calendar events and Google Tasks organized as Markdown notes in an Obsidian vault.

What this integration does

  • Reads existing events from Google Calendar and imports them as Obsidian notes.
  • Reads Google Tasks and imports them as Obsidian notes.
  • Can update existing Google events and tasks after the user edits a linked note and initiates or enables synchronization.
  • Does not create or delete Google Calendar events or Google Tasks.

Why Google access is requested

Google Calendar and Google Tasks permissions are used exclusively to read and synchronize the user's chosen calendar and task data. Write permissions allow the plugin to update existing linked items. The user controls whether and when synchronization runs in the plugin settings.

How privacy works

The plugin runs inside Obsidian and communicates directly with Google's APIs; there is no separately hosted synchronization backend. OAuth credentials are stored in local Obsidian plugin settings. The GitHub Pages callback page only forwards Google's short-lived sign-in response back to Obsidian.

Read the Privacy Policy for more detail, including what data is accessed, where it is stored, and how to disconnect the integration.
